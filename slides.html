§2

Switching Cost — 4 Forces

① Push — Vấn đề với VS Code + Copilot

Copilot chỉ là extension → không deep integrate. Copy-paste context liên tục. Multi-file refactor cực kỳ manual. "AI đang phụ trợ, không phải cộng tác."

② Pull — Sức hút của Cursor

Tab nhảy file. Composer refactor toàn codebase. Agent Mode chạy terminal + fix lỗi tự động. Import VS Code config 1 click → switching gần zero friction.

③ Habit — Thói quen giữ lại

"VS Code là muscle memory 5 năm." Hệ sinh thái extension khổng lồ. Team đã chuẩn hóa workflow. Enterprise IT chỉ approve tool trong whitelist.

④ Anxiety — Nỗi lo chuyển đổi

"AI hallucinate code sai thì sao?" Chi phí usage-based khó budget. Cursor là startup — có tồn tại? Data code có an toàn trên server Cursor?

Lực mạnh nhất giữ user: Pull (Tab + Agent Mode tạo workflow mới) → quay về VS Code cảm thấy "bị cắt tay"

§3

Ba dự đoán — 6–12 tháng tới

Đe dọa Big Tech

Microsoft tích hợp Agent Mode vào VS Code → Cursor phản ứng bằng platform play (Origin + Automations)

Lập luận: Timeline cho thấy Cursor đã mở rộng scope từ editor (Mốc 1–3) sang platform (Mốc 5–7). Tệp enterprise quan tâm toàn workflow (code → review → deploy) — ai sở hữu platform sẽ thắng, không phải editor.

Mở rộng segment

Đẩy mạnh non-developer (PM, designer, data analyst) — UX đơn giản hóa + gói pricing riêng

Lập luận: Tệp user §2 dịch chuyển: power-dev → enterprise → non-dev. Agent Mode (Mốc 5) giảm rào cản kỹ thuật gần zero. Thị trường non-dev lớn hơn nhiều so với chỉ phục vụ dev.

Tính năng + kiếm tiền

"Cursor for Teams" — shared codebase context + custom rules. Pricing hybrid: seat + usage credits

Lập luận: Mốc 6 đã chuyển sang usage-based. Tệp enterprise cần quản lý cost cấp team. Context chia sẻ tạo vòng lặp học mạnh hơn → moat từ dữ liệu proprietary.

Key Takeaway

Cursor không thắng vì "AI giỏi hơn" — mà vì hiểu workflow developer sâu hơn bất kỳ ai.

"Quyết định fork VS Code năm 2023 không phải quyết định kỹ thuật — đó là quyết định product. Nó cho phép Cursor định nghĩa lại 'tốt' là gì, và tạo switching cost mà không extension nào bắt chước được."
